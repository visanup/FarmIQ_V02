Unit mismatch / overweight
37

ปัญหา: บาง session ไก่ยังเคลื่อนที่ระหว่าง capture ทำให้ภาพกับน้ำหนักไม่สัมพันธ์กัน และมีบางเคสที่ค่าหน่วยน้ำหนักผิดเพี้ยน
วิธีแก้: ปรับโค้ด stable-window, จับเวลา image/scale ให้ sync กันมากขึ้น, และ harden final-weight binding ใน pipeline

Multi-detection in ROI
10

ปัญหา: มีไก่มากกว่าหนึ่งตัวเข้ามาใน ROI ทำให้เลือก object เป้าหมายผิดได้
วิธีแก้: ปรับ code ฝั่ง train/inference ด้วยข้อมูลจริงที่มากขึ้น และคัด training set ที่สะท้อนสภาพหน้างานจริง

Low-confidence segmentation
43

ปัญหา: segmentation confidence ต่ำเมื่อภาพจริงมีทับซ้อน แสงไม่นิ่ง หรือมุมมองไม่สมบูรณ์
วิธีแก้: retrain AI model ด้วยข้อมูลจริงที่มากขึ้นและเพิ่มตัวอย่างจาก field experiment จริง

Depth / geometry defects
36 / 10

ปัญหา: วัตถุจริงเคลื่อนที่ ทำให้กล้องโฟกัสหรือความลึกคลาดเคลื่อน ส่งผลต่อ geometry feature
วิธีแก้: แยก class ของ model ให้ detect ไก่ที่เห็นตัวสมบูรณ์และเต็มตัวก่อนนำไปคำนวณน้ำหนัก

False negative มาจาก object ยาก ไม่ใช่ threshold อย่างเดียว
614

ใน NCK false negative พบว่า 56.5% ติดขอบภาพ, 52.8% เล็กมาก, และ 21.5% อยู่ในฉากที่ซ้อนกัน แปลว่า root cause คือ visibility และ segmentation difficulty

False positive บางส่วนเป็น model มั่นใจผิดจริง
46%

ใน NCK false positive มีถึง 46.0% ที่ confidence ตั้งแต่ 0.6 ขึ้นไป จึงไม่ใช่แค่ตั้ง threshold ต่ำ แต่มี bias ไปทางทาย NCK เกินจริงในบริเวณขอบภาพหรือ object ซ้อนกัน

มีสัญญาณเรื่อง label consistency
review required

จาก sample audit พบหลายเคสที่ภาพมีตัวไก่จริง แต่ GT ไม่ครอบตำแหน่งหรือ contour ตามที่ model ทาย จึงต้อง review เพิ่มว่าเป็น annotation policy ไม่สม่ำเสมอหรือไม่

สิ่งที่ทีมแก้แล้ว: แยก evaluate ออกเป็น standard validation และ operational IoU matching, เพิ่ม confusion-matrix analysis ที่อ่าน background ได้ถูกต้อง, และเพิ่ม full evaluation report สำหรับ TP/FP/FN จริง
สิ่งที่ทีมแก้ใน training pipeline: เพิ่ม auto-balance, oversample class CK-S, class weighting, และ copy-paste augmentation เพื่อแก้ class imbalance ที่ชัดเจนใน dataset
สิ่งที่ทีมต้องทำต่อ: cleanup 15 invalid label rows, review ภาพ NCK ที่ติดขอบหรือโดนบัง, ทำ annotation policy ให้สม่ำเสมอ, และ retrain ด้วยข้อมูลจริงที่ balance และยากพอสำหรับ edge/occlusion cases
ข้อสรุปเชิงวิศวกรรม: ปัญหาหลักไม่ใช่การซ่อน background ใน confusion matrix แต่คือ dataset difficulty, label consistency, และ model bias ต่อ NCK ที่ต้องแก้ทั้ง data และ training pipeline
