2. Config 4G Router

2.1 LAN

Router IP : 192.168.1.1
Subnet    : 255.255.255.0
DHCP      : Enable

2.2 DHCP Pool

Start IP : 192.168.1.10
End IP   : 192.168.1.100

2.3 Address Reservation

Edge Wi-Fi MAC -> 192.168.1.120
IoT Wi-Fi MAC  -> 192.168.1.121

ดู MAC Address:

ip -br link

2.4 Wireless Isolation

AP Isolation       = OFF
Client Isolation   = OFF
Wireless Isolation = OFF

IoT และ Edge ต้องเชื่อม SSID หลักเดียวกัน

3. Config Edge / Cloud Ubuntu

3.1 เชื่อม Wi-Fi

ให้ Edge ได้ IP:

192.168.1.120

3.2 ตรวจ IP

ip -br addr

ควรเห็นประมาณ:

wlp2s0    UP    192.168.1.120/24

3.3 ตรวจ Route

ip route

ควรมี:

default via 192.168.1.1 dev wlp2s0

3.4 ทดสอบ

ping -c 4 192.168.1.1
ping -c 4 8.8.8.8
ping -c 4 google.com

4. Config IoT-Layer Ubuntu

4.1 เชื่อม Wi-Fi

ให้ IoT ได้ IP:

192.168.1.121

4.2 ตรวจ Interface

ip -br addr

ตัวอย่าง:

wlp2s0    UP    192.168.1.121/24
enp3s0    UP

ชื่อ interface จริงอาจต่างจากตัวอย่าง ให้ใช้ชื่อที่เครื่องแสดงจริง

4.3 ตรวจ Internet Route

ip route

ต้องมี default route ออก Wi-Fi:

default via 192.168.1.1 dev wlp2s0

5. Config Camera Ethernet บน IoT

เสียบสาย Ethernet จาก IoT ไป PoE Switch และต่อกล้อง .199 / .200 ให้เรียบร้อยก่อน

5.1 เปิด Ethernet

sudo ip link set enp3s0 up

5.2 เพิ่ม IP ให้ Ethernet ของ IoT

sudo ip addr add 192.168.1.122/32 dev enp3s0

192.168.1.122 คือ IP เพิ่มของพอร์ต Ethernet บน IoT เอง ไม่ใช่ IP กล้อง

5.3 Host Route ไป CCTV Left

sudo ip route add 192.168.1.199/32 dev enp3s0 src 192.168.1.122

5.4 Host Route ไป CCTV Right

sudo ip route add 192.168.1.200/32 dev enp3s0 src 192.168.1.122

6. ตรวจ Routing

6.1 CCTV Left

ip route get 192.168.1.199

ต้องออก enp3s0 และ source 192.168.1.122

6.2 CCTV Right

ip route get 192.168.1.200

ต้องออก enp3s0 และ source 192.168.1.122

6.3 Edge

ip route get 192.168.1.120

ต้องออก Wi-Fi และ source 192.168.1.121

6.4 Internet

ip route get 8.8.8.8

ต้องผ่าน 192.168.1.1 ทาง Wi-Fi

9. AnyDesk — Unattended Access

9.1 ติดตั้ง

ติดตั้ง AnyDesk บน IoT และ Edge/Cloud Ubuntu โดยใช้แพ็กเกจ .deb สำหรับ amd64/x86_64 หากเป็นเครื่อง Intel/AMD

9.2 เปิด Unattended Access

Settings
 -> Access / Security
 -> Unattended Access
 -> Set Password

ตั้ง Password แยกกันระหว่าง IoT และ Edge

9.3 ทดสอบไม่ต้องกด Accept

ตั้ง Incoming Session ให้รับผ่าน Unattended Access ตามตัวเลือกของ AnyDesk เวอร์ชันที่ติดตั้ง แล้วทดสอบ Remote จากเครือข่ายภายนอก

ต้องทดสอบ AnyDesk หลัง reboot ทั้งสองเครื่อง เพื่อยืนยันว่า service กลับมาเองและ Remote ได้โดยไม่มีคนหน้างานกด Accept
